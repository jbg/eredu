# Original serial branch placement

The existing resume path already moves the displaced typed decoder into its
paid control slot. The ordinary serial exchange path separately grows retained
owner vectors and invalidates both state revisions, without rebinding the
pending token or the initial opening. Reusing that path for admitted branches
would lose their exact placement association.

The canonical worker remains the typed replicated-session exchange and its
existing distributed preparation vote. A closed pair of completed original
runs holds both run gates, authenticate the installed state and incoming
slot, fund two fresh placement identities before the vote, and returns exact
source-to-destination receipts. The native adapter moves existing owner
rows and rebinds only the actual pending inputs/openings supplied by the core
completed-machine boundary. Model, sampler, observation, transport, copy and
attempt spending remain with their original owners.

Distributed exchange consumes the current request's existing monotone control
cursor and prospectively funded source operation. It does not reset that cursor
or reuse a prior occurrence. The public core/facade driver owns machine and
semantic movement after the native atomic endpoint succeeds.

The paired run-gate tests and existing sampling-gate regression tests pass. The
native library and test surface typecheck with the exact placement endpoint.
Subsequent public native tests also pass the exercised ordinary and authenticated

insufficient evidence of native numerical or distributed behavior.

Child capture limits use the same declaration copy and canonical streaming
identity worker as ordinary capture. The new source retains its exact parent;
equal declarations from another owner do not establish that relationship. The
new checkpoint keeps the snapshot's absolute coordinates and spent capture
usage, and can only populate an independent child bank. It cannot restore or
replace the parent's cumulative ledger. The original source witness retains
prior paid custody while the new declaration obtains its own publication.

The focused child-limit test exercises an inherited capture, one additional
allowed child capture, rejection of an independent equal parent, refusal below

output and chunk positions and StateOnly output. The shared scheduler emits no

Graph and record reducers accept this authenticated empty equation range while
