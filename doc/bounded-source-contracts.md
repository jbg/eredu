# Source, capture and continuation contracts

## Capture and records

Capture delivery is fallible and retains the immutable frame owner, including
pending or failed native custody. Draining does not convert a paid record into
an unowned tensor. Diagnostic wire decoding creates diagnostic ownership; it
does not recreate an allocation grant. Record outcomes are explicit, including
the supported `Untracked` outcome.

Recorded chat owns a `PreparedChatSession` and a funded journal. Text and semantic
output, token input, media and observations are policies on that session. The
journal uses paid prompt attribution and the same advancement and commitment
driver as uninterrupted generation. Snapshots retain complete mutable state
without resetting observation, transport or copy spending.

## Cancellation and prefill

The prefill contract carries a cancellation token and exact boundary. Each span
retires its submitted work before sampling cancellation and entering distributed
agreement. A control vote authenticates the request, source and monotone
occurrence. Source failure remains typed and retains its payer; cancellation
does not convert unresolved native work into completed work.

## Parameter and metadata destinations

Parameter visitors borrow names, shapes, values and graph declarations. Owners
that outlive a visit reserve and construct their actual destination. This covers
state layouts, media metadata, parallel boundaries, collective manifests,
observation bindings and materialization recipes. Retaining an existing table
does not pay for an independent map, string, wrapper or support report.

Partition capture uses the same placement, catalog, support and fingerprint
workers for ordinary and funded construction. Exact loaded owner identity is
required for parameter aliases and native bindings. Fresh artifacts receive
their own funded identity. Cold inspection reads declarations and backend facts
without allocating native tensors or selecting devices.

`GroupSubmissionMechanism::{LayeredGraph, PolicyOnly}` describes whether the
selected executor submits graph groups or traverses them manually. Quotes count
actual submissions while retaining the resident parameter registry, source,
stream and request custody. Resident partitions borrow their selected policy
owner. Family names do not choose the submission mechanism.

## Branch placement and sampling

Completed branch exchange holds both run gates, authenticates installed state
and incoming slots, funds placement identities and performs the distributed
preparation vote. The adapter moves owner rows and rebinds the supplied pending
inputs and openings. The facade moves machine and semantic state after the
native endpoint succeeds. Sampling, observation, transport and copy accounts
stay with their owners.

Child capture limits retain the exact parent declaration and absolute snapshot
coordinates. A derived child bank cannot replace the parent's cumulative ledger.
Child intervention replacement projects requested targets from the retained
loaded declaration and collector facts under its own funding. Sampling changes
validate temperature/RNG compatibility, prepare the replacement key, establish
completion and publish the key and temperature together.

Terminal restoration copies the saved cache frontier with zero input/output
positions and `StateOnly` output. It produces no model span or prediction.
Empty capture banks preserve spending. Parallel control custody is retained
independently of model rows so empty placement can use the same exchange vote.

## Shared diagnostic ownership

`IncrementalInferenceQuote` and `ResidualInferenceQuote` share a paid immutable
`RuntimeStateEstimate`, including diagnostics and sliding-window rows. Neural
errors retain their typed source; caller-owned diagnostic text is a distinct
message value. A reached allocation refusal preserves the first cause and payer.

and [validation](bounded-inference-validation.md) for conformance scope.
