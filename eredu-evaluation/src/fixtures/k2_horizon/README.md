# K2 Horizon conformance inputs

`numerical.json` contains the independent NumPy FP32 expectations and synthetic
parameters generated by `eredu-architectures/tests/fixtures/k2_horizon/generate_reference.py`.
`text.json` and the four Jinja templates contain the publisher-template cases
produced by `eredu-text/tests/fixtures/k2_horizon/generate_reference.py`.
`tool-generation.json` contains the publisher-generated tool-call outputs and
their recorded generation settings for streaming parser conformance.
The originating crates retain their local reference inputs for their own tests.

`sources.json` records the source paths and SHA-256 digests of these exact copies.
`provenance.json` retains the original template hashes and reference environment.

packaged fixtures, rerun the corresponding generator, copy the resulting files
here using the names in `sources.json`, and update those digests. Consumers use
the exported constants in `eredu_evaluation::fixtures::k2_horizon`.
