# VoiceChat reference provenance

`sources.json` identifies the independent NVIDIA sources used to understand the
family equations and request policy. It contains no weights or numerical traces.
Complete-model independent numerical acceptance is unvalidated; see
[VoiceChat validation](../../../doc/voicechat-validation.md).

Run narrow investigations outside the tracked tree. Retained acceptance compares
the same released artifact, PCM/tool inputs and cached frame sequence, including
score rows, committed tokens and waveform output.
