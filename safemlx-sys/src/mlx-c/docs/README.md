# MLX C API documentation sources

This directory contains the Doxygen configuration and supporting files for the
vendored MLX C API reference. It is not the Eredu user guide and is not built
as part of a normal Cargo build.

Rust users should consult `eredu` Rustdoc and the [Eredu documentation
index](../../../../doc/README.md). Backend implementers working directly with
MLX may also need the `safemlx` Rustdoc. The rendered upstream C reference is
available from the [MLX C documentation](https://ml-explore.github.io/mlx-c/).
